# Os Dois Lados do Mesmo Pensamento — fila de pedidos

Pedidos do autor guardados aqui para serem feitos **todos de uma vez**, numa única atualização do livro
(um DOCX novo no final), em vez de gerar o livro a cada pedido.

Como usar: o autor manda os pedidos quando quiser; o Claude só anota aqui. Quando o autor disser
**"pode executar a fila"**, o Claude aplica tudo, gera o livro uma vez e marca cada item como feito.

## Aguardando o autor
- [ ] Dedicatória (para quem e o texto) — opcional
- [ ] Subtítulo — opcional
- [ ] Consentimento da filha para a história do transplante no Cap. 6
- [ ] Leitura das páginas alteradas em 03/11 (lista abaixo)

## Depois do texto fechado
- [ ] Capa: ampliar para 300 dpi e resolver o título amarelo sobre amarelo
- [ ] PDF final, envio à UICLAP e capa completa com a lombada que a UICLAP calcular
